# Deogracia Olweny - Developer Portfolio

Welcome to the repository for my personal developer portfolio! This project is a fully responsive, multi-lingual website designed to showcase my software development skills, projects, professional experience, and community leadership.

## 🌟 Features

- **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Dark/Light Mode:** A seamless theme toggle with saved user preference (via `localStorage`).
- **Multi-Language Support:** Built-in translation engine supporting English (ENG), French (FRE), and Russian (RUS).
- **Dynamic Sidebar:** A hidden desktop sidebar with a smooth toggle, and a mobile hamburger menu for smaller screens.
- **Interactive Project Gallery:** Filterable project showcase with hover/focus overlays.
- **Smooth Animations:** Scroll-reveal animations and typing effects in the hero section.
- **Accessible:** Built with semantic HTML, ARIA labels, and keyboard navigability in mind.

## 🛠️ Tech Stack

This project is built using core web technologies without heavy frameworks, ensuring fast load times and a lightweight footprint:
- **HTML5:** Semantic structure and accessibility.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, media queries, and animations.
- **Vanilla JavaScript:** DOM manipulation, theme toggling, translation logic, and intersection observers.
- **Bootstrap Icons:** For scalable, clean vector icons.
- **Google Fonts:** Poppins, Raleway, and Roboto.
